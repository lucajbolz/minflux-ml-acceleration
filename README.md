# ML for MINFLUX Distance Estimation

XGBoost model for fast MINFLUX distance estimation. Replaces iterative MLE with single-pass inference.

**Results:** 3.2 nm RMSE, 0.2 ms inference time

**Data:** Hensel et al., *Nature Physics* (2024) — [Paper](https://www.nature.com/articles/s41567-024-02760-1) · [Data](https://zenodo.org/record/10625021)
