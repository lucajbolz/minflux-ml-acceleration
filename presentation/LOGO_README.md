# MPI Logo für Präsentation

Um das MPI-Logo in der Präsentation anzuzeigen:

1. **Logo-Datei hinzufügen:**
   - Dateiname: `mpi_logo.png` oder `mpi_logo.pdf`
   - Ablageort: Gleicher Ordner wie `main-2.tex`

2. **In main-2.tex aktivieren:**
   - Zeile 34 auskommentieren (% entfernen):
   ```latex
   \logo{\includegraphics[height=0.8cm]{mpi_logo.png}}
   ```

3. **Logo-Größe anpassen (optional):**
   - Parameter `height=0.8cm` nach Bedarf ändern
   - Empfohlen: 0.6cm bis 1.0cm

Das Logo erscheint dann rechts unten auf jeder Folie.
